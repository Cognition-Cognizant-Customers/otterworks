## Notes and discrepancies found in tooling

- **`frontend/web-app` does not exist.** The `frontend/` directory contains only
  `client-app` and `admin-dashboard`, but the root `Makefile` references
  `frontend/web-app` in three targets: `build-web` (Makefile line 107), `test`
  (line 125), and `lint` (line 150). Those Makefile steps fail with "No such file
  or directory". `docker-compose.yml` is correct — its `web-app` service builds from
  context `./frontend/client-app`.
- **`services/legacy-portal` is absent from the root `docker-compose.yml`** (it ships
  its own `services/legacy-portal/docker-compose.onprem.yml`) and from the Makefile
  `test`/`lint` aggregates (Makefile lines 114–151), although it does have a CI job
  (ci.yml lines 339–353).
- **`services/report-service` is absent from the Makefile `test` aggregate** (lines
  114–126); it has its own `test-report`/`build-report` targets (lines 229–233) and is
  explicitly skipped by `security-scan` (line 227).
- `docker-compose.yml` sets `SEARCH_SERVICE_URL` in the file-service environment, but
  no code under `services/file-service/src/` reads it.
- `ARCHITECTURE.md` describes the web frontend as "React/Next.js"; the actual app is
  React 18 + Vite (`frontend/client-app/package.json` scripts `dev: vite`,
  `build: tsc --noEmit && vite build`).
